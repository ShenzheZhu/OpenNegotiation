# Naming Policy

OpenNegotiation is the public-facing product name.

Use `OpenNegotiation` in:

- reports and demo pages
- README and public documentation prose
- user-facing prompts, package handoff text, and marketplace profile copy
- paper-facing descriptions of the gym

Keep `OpenNego` or `opennego` only as technical identifiers:

- GitHub repository handle: `Kordi-AI/OpenNego`
- Python package and import path: `opennego`
- CLI command: `opennego`
- artifact schema ids: `opennego.*`
- existing generated filenames where path compatibility matters

Do not rename the Python package, CLI command, schema ids, or repository as
part of public-copy edits. Those are compatibility handles, not product copy.
