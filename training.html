LiteLLM User Agent

Run a live model as the user-owned buyer or seller, then rerun with a generated strategy candidate.

opennego spar \ --opponent-profile seller_hardline_anchor_v1 \ --user-llm-model openrouter/openai/gpt-4.1-nano \ --opponent-llm-model openrouter/openai/gpt-4.1-mini

Local AgentPort

Strategy Candidate

Convert a battle report into strategy instructions and feed them back into the next user-agent run.

opennego evolve \ --battle-report battle_report.json \ --output strategy_candidate.json opennego spar --user-strategy strategy_candidate.json

Battle Report to Strategy Patch

The toolkit turns run artifacts into specific edits users can copy into their strategy layer. It should explain what failed, where it happened, and how to rerun the test.

Battle Report

Outcomedeal at $608.00

The accepted price is more than 5% above market reference. Evidence points to the final buyer offer and seller accept turn.

Generated Strategy Patch

Role strategy patch for buyer: Keep the OpenNegotiation gym contract stable. Edit only the strategy layer. 1. Never exceed market_reference * 1.05 unless a written exception is justified by condition, bundle value, warranty, or time preference. 2. Before accepting, compute all-in price: item + shipping + fees + tax. 3. If the seller anchors above market, ask for one concrete condition or bundle justification before increasing the offer.

Toolkit Surface

These are the current commands and APIs for a small, repeatable improvement loop over the same NPC curriculum.

CLI Loop

opennego spar --output-dir /tmp/baseline --opponent-profile seller_hardline_anchor_v1 opennego evolve --battle-report /tmp/baseline/profiles/seller_hardline_anchor_v1/battle_report.json --output /tmp/strategy_candidate.json opennego spar --output-dir /tmp/rerun --opponent-profile seller_hardline_anchor_v1 --user-strategy /tmp/strategy_candidate.json opennego compare --before /tmp/baseline/profiles/seller_hardline_anchor_v1/battle_report.json --after /tmp/rerun/profiles/seller_hardline_anchor_v1/battle_report.json --output /tmp/strategy_comparison.json
